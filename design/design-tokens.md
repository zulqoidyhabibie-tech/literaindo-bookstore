# Design tokens

Sumber: Blueprint bagian 2.1. Diterapkan sebagai CSS custom properties di
`wordpress/themes/literaindo-child/assets/css/main.css`.

| Token | Nilai | Penggunaan |
|---|---|---|
| `--lit-navy` | `#173B57` | Warna utama, navigasi, tombol primer, judul |
| `--lit-navy-dark` | `#0F2A40` | Hover tombol primer, latar footer |
| `--lit-ivory` | `#F7F3EA` | Latar halaman dan area editorial |
| `--lit-maroon` | `#873E4A` | Aksen promosi, tombol beli, fokus keyboard |
| `--lit-stone` | `#E8E5DE` | Garis pemisah, permukaan sekunder |
| `--lit-ink` | `#2B2F33` | Teks isi |
| `--lit-muted` | `#5D6670` | Teks sekunder (kontras ≥ 4,5:1 di atas ivory) |
| `--lit-font-serif` | Noto Serif | Judul halaman, judul buku |
| `--lit-font-sans` | Inter | Isi, label, tombol, navigasi |

Aturan tombol: tombol primer (navigasi, "Jelajahi Buku") memakai navy; tombol
transaksi ("Tambah ke Keranjang", checkout, "Buat Pesanan") memakai maroon agar
mudah ditemukan.
