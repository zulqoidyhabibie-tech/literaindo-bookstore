# Checklist Peluncuran

Berdasarkan Blueprint bagian 12. Centang sebelum website dipakai untuk transaksi nyata.

## Fungsi

- [ ] Halaman utama berfungsi baik di desktop dan ponsel.
- [ ] Pencarian (judul, penulis, ISBN), kategori, filter format, dan pengurutan bekerja.
- [ ] Admin dapat menambah, mengedit, dan mengarsipkan produk.
- [ ] Harga dan stok buku cetak diperbarui dengan benar.
- [ ] Checkout menghitung subtotal, diskon, ongkir, dan total dengan akurat.
- [ ] Status pembayaran berubah hanya setelah admin mengonfirmasi dari mutasi BTN.
- [ ] E-book hanya dapat diakses pelanggan yang berhak (uji D6, D8–D10).
- [ ] Email konfirmasi pesanan dan pembaruan status terkirim dan tidak masuk spam.
- [ ] Hak akses Administrator dan Manajer Toko telah diuji.
- [ ] Transaksi uji dari awal hingga selesai berhasil (cetak dan e-book).

## Konten

- [ ] Halaman Tentang Kami, Bantuan, Syarat Transaksi, Pengiriman/Retur/Refund,
      Ketentuan E-book, dan Kebijakan Privasi sudah dilengkapi, ditinjau, dan terbit.
- [ ] Tidak ada lagi teks `[dalam kurung siku]` di halaman mana pun.
- [ ] Buku contoh/uji dihapus; pesanan uji dihapus atau dibatalkan.
- [ ] Logo, kontak, dan identitas CV benar.

## Keamanan dan operasional

- [ ] HTTPS aktif di semua halaman.
- [ ] 2FA admin dan batas percobaan login aktif.
- [ ] Folder bukti bayar menolak akses langsung (uji D3).
- [ ] Backup otomatis berjalan dan uji pemulihan berhasil.
- [ ] Email SMTP terkonfigurasi.
- [ ] WooCommerce → Persiapan Toko: semua butir ✓.
- [ ] Tema/plugin tidak terpakai dihapus; akun uji dan akun developer dinonaktifkan.

## Serah terima

- [ ] Daftar tema, plugin, versi, dan lisensi dicatat (WooCommerce → Status → *Dapatkan laporan sistem*).
- [ ] Panduan admin diserahkan ke staf.
- [ ] Akses admin diserahkan dengan aman.
